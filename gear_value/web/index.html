Как считается ориентир

Сравниваются одинаковые название, тип, редкость, усиление, особая метка, число оставшихся попыток торговли, набор базовых и особых характеристик. Для значений допускается отличие до 12% от большего значения или 0,15 процентного пункта. Цвета известных характеристик должны совпадать; значения урона ниже и выше 4,5% разделяются.

Это правила подбора аналогов, а не доказанная модель рынка. Они не назначают цену характеристикам. Медиана и диапазон берутся непосредственно из подходящих наблюдений без надбавок и коэффициентов. Для оценки по продажам нужны 3 сделки; иначе показан только ориентир по ценам продавцов. Текущие ставки, непроданные лоты и совпадения одной характеристики показаны отдельно.

Повторы с одинаковыми параметрами, ценой и статусом объединяются даже за разные даты; учитывается самый свежий. Это консервативное правило может объединить разных продавцов. Исчезновение объявления не подтверждает продажу. Время до продажи и вероятность продажи не рассчитываются без истории. Выбранный лот исключается из оценки самого себя.

Экспорт содержит записи; снимки хранятся локально отдельно. Импорт добавляет новые записи, сохраняя существующие. Перед изменением базы создаётся резервная копия.
