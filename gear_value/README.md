# Оценка снаряжения Doomsday — отдельное приложение

Первая версия для обкатки оценки **стоимости снаряжения отряда в золоте**.
У приложения свои исходники, запуск и база; зависимости от BuZzbot нет.

## Запуск

Скачайте `DoomsdayGearValue.zip` из [отдельного релиза оценщика](https://github.com/ValeraBuZ/BuZzbot-PC/releases/tag/gear-latest)
и полностью распакуйте архив. Он собирается независимо от бота; устанавливать BuZzbot не нужно.

Запустите `DoomsdayGearValue.exe`. Версия 0.5.2 открывает отдельное окно Windows.
Интернет и браузер для работы не нужны. Закрытие окна останавливает приложение.
Повторный запуск поднимает уже открытое окно.

Из исходников, из родительской папки:

```powershell
py -3.11 -m pip install -r gear_value/requirements.txt
py -3.11 -m gear_value.desktop
```

Для запуска исходников нужны Python 3.11 и зависимости из requirements.txt. Готовый EXE уже содержит их. LDPlayer необязателен.
Откройте карточку предмета в игре, сделайте снимок Win+Shift+S, затем нажмите Ctrl+V в оценщике.
Можно нажать «Вставить скриншот» или выбрать PNG/JPG/WebP через «Выбрать скриншот». Поддерживается и скопированный файл изображения из Проводника.
Снимок распознаётся локально без отправки в интернет. Снимки для оценки не сохраняются на диск: временные файлы OCR удаляются, предпросмотр остаётся в памяти до смены предмета или закрытия программы. После распознавания проверьте поля. Непрочитанные числа остаются пустыми; усиление без видимого +N укажите вручную (0 для вещи без усиления).
Поддерживаются компактные карточки и снимки всего экрана инвентаря, в том числе названия с переносом на две строки («+20 Противотанковая мина»). Усиление берётся из выбранной карточки, а не из соседних вещей. Базовые характеристики с пометкой «(Пехота)» распознаются отдельно от общих характеристик отряда.
Оцениваются только золотые (легендарные) вещи. Форма всегда содержит две базовые и три особые характеристики; непрочитанные поля остаются пустыми. Другие редкости не оцениваются и не добавляются автоматически. Старые записи в базе сохраняются.
Старая версия страницы и захват через ADB доступны отдельно через `--web`. Основное окно не зависит от локального сервера.

## Что уже есть

- Итог показывает цену вещи целиком и отдельные сравнения по каждой особой характеристике. Если строгого аналога нет, виден пример с другим процентом и его фактической ценой. Другой цвет, дополнительные сильные строки, связки и метки отмечаются рядом. Полный разбор открывается кнопкой «Показать сравнения и источники».
- Названия распознаваемых характеристик совпадают с русской карточкой игры. Полученный урон контратаки отображается с минусом, «СНИЖ УРН пехотного отряда» — без минуса, как в игре. Расчёт сохраняет величину показателя.
- В комплекте 238 наблюдений: 130 цен объявлений от 26.09.2026 и 108 показанных лучших ставок из зала торгов от 27.09.2026, с полными параметрами и снимками.
- Вставка скриншота через Ctrl+V и загрузка файла с локальным OCR Windows, без HTTP-запросов.
- Ручной ввод предмета и цены, исправление распознанных полей, поиск, удаление, импорт и экспорт JSON.
- Статусы «выставлено», «текущая ставка», «продано», «не продалось».
- Сравнение с той же категорией, редкостью, усилением, особой меткой,
  оставшимися попытками торговли, базовыми и особыми характеристиками.
- Четыре категории: шлем, оружие, жилет, устройство. Название вещи служит подписью и не влияет на расчёт или отбор аналогов.
- Раздел «За что могут заплатить»: подборки по одной главной строке для переплавки и по связкам.
- Для одной строки не требуется совпадение названия, усиления или фоновых параметров. Сохраняются категория, редкость, тип, цвет и значение ±0,1 процентного пункта. Другие значения показаны справочно.
- Справочные примеры по отдельным строкам видны сразу, даже если оценка целой вещи невозможна. Предпочитаются тот же цвет и предметы без другой явно сильной строки или метки, затем ближайшее значение. Эти примеры не включаются в строгую оценку, их цены не пересчитываются пропорционально процентам и не складываются.
- Для связок сохраняются категория, усиление, базовые характеристики, особая метка, попытки торговли и близкие значения главных строк. Дополнительные сильные боевые строки не смешиваются с обычным фоном.
- Медианы и разброс цен продавцов, показанных лучших ставок и подтверждённых сделок разделены. Их суммы не складываются.
- Возраст наблюдений и рынок фильтруются. Выбранный лот исключается из собственной оценки.
- Разбор англоязычных и японских источников со ссылками, сверка спроса и примеры цен без подтверждённых продаж.
- Вручную проверены 138 скриншотов пользователя: добавлены 125 новых лотов, исключены 13 повторов относительно общей базы.
- Дополнительно проверены 108 снимков зала торгов №146–253. Повторов внутри нового пакета нет. Поле «Лучшая ставка» не доказывает наличие ставки покупателя: оно может показывать начальную сумму. Все эти строки имеют статус «Текущая ставка», ноль из них помечены как завершённые продажи.
- Текущая выборка включает дорогую часть списка и не является случайной выборкой рынка.

## Ограничения первой версии

Это небольшой журнал рынка, а не готовый прайс-лист всего снаряжения.
В первой выборке нет подтверждённых продаж, поэтому реальную цену продажи пока определить нельзя.
При недостатке полных аналогов приложение честно показывает отсутствие оценки.
Цены отдельных характеристик не складываются: наценка за сочетание не выдумывается.
Завершённая сделка подтверждается пользователем по журналу торговли.
Исчезновение лота не считается продажей. Вероятность и скорость продажи не прогнозируются.

Для строгого сравнения всей вещи допускается отличие в характеристиках до 12% от большего значения или
0,15 процентного пункта. Это выбранный критерий близости, который ещё предстоит
проверить на большей выборке. Заданные цвета должны совпадать. Граница 4,5% для
урона/снижения урона сравнивается отдельно. Повторяющиеся характеристики сохраняются раздельно.
Вещи с разными названиями внутри одной категории сравниваются одинаково.
Любая комиссия в расчёте задаётся вручную и не выдаётся за подтверждённый тариф игры.

По японским источникам изучены сообщения о рынке и собственные торги автора.
Китайские и корейские публичные цены не собраны: для ряда форумов чтение ограничено.
Форумные примеры не выдаются за лично проверенные завершённые сделки.

## Автопополнение

Рядом с EXE находится папка **Новые скриншоты**. Сохраняйте туда новые полные снимки аукциона: на них должны быть видны карточка выбранного лота и его цена. Во вкладке «Автопополнение» можно открыть папку, приостановить обработку или проверить неразборчивый снимок.

Пока программа открыта, новые файлы читаются автоматически. Уверенно распознанные характеристики и цена записываются в базу, полный прочитанный текст — в `import_log.json`. Только после успешной записи исходный файл удаляется из этой папки. Дополнительная копия изображения не создаётся. Повторные лоты не умножают наблюдения. Перед удалением приложение проверяет, что файл не изменился.

Неразборчивые снимки и карточки без цены остаются в папке. Выберите строку на вкладке «Автопополнение», нажмите «Проверить выбранный снимок», исправьте поля и сохраните наблюдение цены. После успешного сохранения этот снимок тоже удалится. Дата наблюдения берётся из времени изменения файла; для старых снимков её нужно проверить.

Сумма проверяется двумя чтениями. Автоматически записываются только объявления и показанные лучшие ставки. Подтверждение завершённой продажи остаётся ручным. Снимок инвентаря без цены не добавляется как наблюдение аукциона.

Удаление относится только к обработанным файлам в папке «Новые скриншоты». Ранее собранные снимки и файлы в других папках автоматически не удаляются.

## Где данные

По умолчанию: `%LOCALAPPDATA%\DoomsdayGearValue`.
`market.json` — база, `market.json.bak` — предыдущая версия, `import_log.json` — текстовый журнал автопополнения. Папка `screenshots` может содержать снимки от предыдущих версий.
Проверенные карточки 238 лотов встроены в EXE. Экспорт JSON содержит записи, но не изображения.
Для переноса новых снимков скопируйте папку `screenshots` отдельно.
Повторный экземпляр с той же базой блокируется, чтобы сохранить наблюдения.
Основное окно не открывает сетевой порт и не отправляет снимки в интернет. Необязательный режим `--web` слушает только `127.0.0.1`.
Ссылки на источники открываются по нажатию в браузере.

## Проверка и сборка

Из родительской папки:

```powershell
py -3.11 -m pip install -r gear_value/requirements.txt pyinstaller==6.22.2
py -3.11 -m unittest discover -s gear_value/tests -v
py -3.11 gear_value/build.py
```

Для сборки нужны зависимости из requirements.txt и PyInstaller. OCR требует установленный русский язык распознавания Windows; на этом компьютере он доступен. Приложение и инструкция попадут в
`gear_value/dist/DoomsdayGearValue`. Сборка бота не затрагивается.

GitHub Actions запускает тесты и собирает отдельный ZIP при изменении этой папки в ветке `main`.
Последняя успешная сборка публикуется с тегом `gear-latest`; релиз бота `latest` остаётся отдельным.
