# BuZzbot

Windows-бот для Doomsday: Last Survivors в LDPlayer 9. Программа автоматически проверяет ADB и живое разрешение LDPlayer, подгоняет шаблоны и координаты, а затем выполняет выбранные рутинные задачи.

В репозитории два самостоятельных Windows-приложения:

| Приложение | Исходники и инструкция | Готовая сборка |
| --- | --- | --- |
| BuZzbot 3.9.45 — автоматизация игры | Этот раздел | [BuZzbotPortable.zip](https://github.com/ValeraBuZ/BuZzbot-PC/releases/tag/latest) |
| Оценщик снаряжения 0.5.2 — оценка по наблюдениям аукциона | [gear_value](gear_value/README.md) | [DoomsdayGearValue.zip](https://github.com/ValeraBuZ/BuZzbot-PC/releases/tag/gear-latest) |

У оценщика свои зависимости, база данных, тесты и сборка. Для его работы бот и LDPlayer не нужны.

## Скачать готовую версию

1. Откройте раздел **Releases** репозитория.
2. Выберите релиз **Последняя portable-сборка**.
3. Скачайте `BuZzbotPortable.zip`.
4. Распакуйте ZIP полностью и запустите `BuZzbot.exe`.

`BuZzbot.exe` содержит Python и Tcl/Tk внутри себя и больше не зависит от папки
`_internal`. Для полноценной работы бота держите рядом с EXE файл `config.json`
и папку `img` из архива. Не запускайте программу прямо из ZIP.

## Рутинные задачи

Текущая версия — **3.9.45**. После 3.9.11 добавлены режим «Свои сборы»,
проверка игрового ID при входе и исправления поиска целей, возврата отрядов,
радара, торговца, лечения и других задач. Подробности и границы проверки — в
[`CHANGELOG.md`](CHANGELOG.md).

В задаче **Подарки альянса** можно отдельно выбрать награды за активность и за
покупки. Награды за активность собираются общей кнопкой, подарки за покупки —
по одному без подписки. Бот проверяет получение и просматривает список в обоих
направлениях, если после сдвига карточек остались подарки.

При переключении IGG бот дожидается подтверждения входа в самой игре. После
исчерпания войск оставшиеся задачи сбора ресурсов пропускаются до следующего
прохода этого аккаунта.

## Отчёт об ошибке

Нажмите в программе **Создать отчёт**. Полученный ZIP можно передать разработчику: конфиденциальные поля конфигурации автоматически скрываются.

## Разработка

```powershell
py -3.14 -m pip install -r requirements.txt
py -3.14 -m unittest discover -s tests -v
py -3.14 build_portable.py
```

Изменения бота в ветке `main` запускают его тесты и создают ZIP в GitHub Actions.
Тег `latest` содержит последнюю успешную portable-сборку бота. Изменения только
в `gear_value` запускают отдельную проверку и сборку оценщика с тегом `gear-latest`.
Обе сборки можно запустить вручную во вкладке Actions.

Рабочие `config.json`, логи, отчёты, снимки обучения и папки `build/dist` намеренно не хранятся в GitHub.

## Android

Начат отдельный мобильный перенос без ПК и эмулятора. Android-версия ограничена тремя сценариями: лечение войск, убийство зомби и охота за призом. Исходники, инструкция и статус MVP находятся в [`android_samsung_mvp`](android_samsung_mvp/README.md).
