# BuZzbot Android

Мобильная ветка BuZzbot работает прямо на Android без LDPlayer и ПК. В версии `0.2.0` оставлены только три сценария:

- лечение войск;
- убийство зомби;
- охота за призом.

## Что уже перенесено

- Нажатия через `AccessibilityService` без root-доступа.
- Захват экрана через штатный `MediaProjection`.
- 23 встроенных визуальных шага из рабочего профиля Windows: 4 для лечения, 7 для зомби и 12 для охоты за призом.
- Выбор задач на главном экране и отдельная настройка повтора охоты за призом.
- Сценарный порядок: шаг выполняется только после нужных предыдущих шагов, включая разные ветки результата охоты.
- Автоматический пересчёт шаблонов и координат с эталона `1280x720` на разрешение телефона.
- Плавающая панель поверх игры, диагностика кадра и редактор шаблонов для калибровки на телефоне.
- Автоматический запуск пакета `com.igg.android.doomsdaylastsurvivors`.

## Установка и первый запуск

1. Собери и установи `app-debug.apk` либо открой эту папку в Android Studio.
2. Запусти BuZzbot в альбомной ориентации.
3. Нажми **1. Включить спец. возможности** и включи сервис BuZzbot.
4. Вернись в приложение и нажми **2. Разрешить захват экрана**.
5. Отметь нужные задачи.
6. Нажми **3. Запустить выбранные задачи**. Приложение откроет Doomsday автоматически.
7. Для экстренной остановки используй плавающую панель или кнопку **Остановить бота**.

Android каждый раз заново запрашивает разрешение на захват экрана после остановки сервиса или перезагрузки телефона — это системное ограничение.

## Сборка

Требования: Android Studio с JDK 17 и Android SDK 35.

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.

## Текущие ограничения MVP

Это основа переноса, а не готовая версия для многочасовой работы без присмотра. Шаблоны взяты из LDPlayer-профиля `1280x720`; масштабирование уже реализовано, но пороги и области поиска нужно проверить на живом Samsung и при необходимости переобучить через раздел **Диагностика и шаблоны**.

Отдельно ещё предстоит перенести специальные защитные действия Windows-бота:

- точный ввод размера партии лечения;
- проверку и отключение лагеря после атаки зомби;
- понижение уровня зомби, резерв выносливости и восстановление после занятых походов;
- расширенное восстановление экранов и проверку результатов каждого сценария.

До этой калибровки сначала используй **Найти лучший шаг** и **Найти и нажать один шаг** на каждом ключевом экране, а автоматический цикл запускай под наблюдением.
